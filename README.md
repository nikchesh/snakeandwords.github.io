# Privacy Policy

This Privacy Policy applies to the **SpellSnake** mobile application (the "Application"), created by **Cheshov Nikolay** (the "Developer") as a free application.

By using the Application, you agree to the practices described in this Privacy Policy.

## Information the Application Processes

The Application may process the following information:

- a nickname or profile name provided by the user;
- user-created words, translations, and categories;
- learning progress, game progress, and app settings stored on the device;
- text entered by the user when using the automatic translation feature;
- technical and usage data collected through analytics services, as described below.

## How the Information Is Used

The Application uses this information to:

- display the user profile inside the app;
- save progress and settings;
- allow users to create and manage their own study categories;
- request translation results when the user uses the automatic translation feature;
- understand how users interact with the Application;
- diagnose technical issues and improve the Application;
- measure the effectiveness of advertising campaigns.

## Local Storage

Certain information, such as profile data, progress, settings, and user-created categories, may be stored locally on the user’s device.

The Developer does not provide account-based cloud storage in the current version of the Application.

## Third-Party Translation Service

When the user uses the automatic translation feature, words or text entered by the user may be sent to the third-party translation service **MyMemory (Translated S.r.l.)** in order to return translation results.

The Developer does not control how the third-party translation service processes data once it is received by that service. Users should avoid entering personal, sensitive, or confidential information into translation fields.

More information about MyMemory is available here:

- Terms and Conditions: https://mymemory.translated.net/terms-and-conditions
- Usage Limits / API Information: https://mymemory.translated.net/doc/usagelimits.php

## Analytics and Advertising Attribution

The Application uses **AppMetrica**, a third-party analytics and advertising attribution service provided by Yandex, to understand how users interact with the Application, diagnose technical issues, improve the Application, and measure the effectiveness of advertising campaigns.

The Application may send technical and usage data to AppMetrica, including:

- app launch events;
- game start events;
- game over events;
- word collection events;
- tutorial start events;
- tutorial completion events;
- technical diagnostics, crash reports, and app performance data;
- device or app identifiers used for analytics and advertising attribution, where applicable.

The Application may send the following non-personal event parameters to AppMetrica:

- category ID;
- game mode;
- difficulty;
- word length.

The Application does **not** send the following data to AppMetrica:

- entered words;
- translations;
- email address;
- phone number;
- avatar;
- nickname;
- user-generated text;
- personal messages or contacts.

AppMetrica processes data according to its own data processing practices. More information about AppMetrica is available here:

- AppMetrica: https://appmetrica.yandex.com/
- AppMetrica Data Safety Information: https://appmetrica.yandex.com/docs/en/data-security/google-data-safety

## Advertising

The current version of the Application does **not** display third-party ads inside the Application.

However, the Application may use analytics and attribution tools, including AppMetrica, to measure the effectiveness of advertising campaigns that promote the Application.

## Data Sharing

The Application may share limited data with third-party services only as described in this Privacy Policy:

- user-entered text may be sent to MyMemory when the automatic translation feature is used;
- technical and usage data may be sent to AppMetrica for analytics, diagnostics, and advertising attribution.

The Application does not intentionally share user data with the Developer’s own servers.

## Data Retention and Deletion

Data stored locally on the user’s device remains there until:

- the user deletes it within the Application, if such functionality is available;
- the user clears the app’s data through the device settings;
- the user uninstalls the Application.

The Developer does not provide account-based cloud storage or account deletion functionality in the current version of the Application.

For data processed by third-party services, such as MyMemory or AppMetrica, retention and deletion may be governed by the policies of those services.

## Children

The Application is not intended to knowingly collect personal information from children. If you believe that a child has provided personal information through the Application, please contact the Developer so that appropriate steps can be taken.

## Security

The Developer takes reasonable steps to protect information processed by the Application. However, no method of electronic storage or transmission over the Internet can be guaranteed to be completely secure.
